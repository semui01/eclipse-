# Eclipse Seasons — why eclipses come in pairs

A 1:16 narrated motion-graphics explainer built around the August 2026 eclipse pair
(total solar eclipse on 12 Aug, partial lunar eclipse on 28 Aug).

| File | Format | Audio |
| --- | --- | --- |

| `eclipse_seasons_16x9_noVO.mp4` | 1920×1080 | music only |
| `eclipse_seasons_9x16_VO.mp4` | 1080×1920 | narration + music |
| `eclipse_seasons_9x16_noVO.mp4` | 1080×1920 | music only |

## Source (`source/`)

- `script.txt` — narration script (`*word*` marks caption highlights)
- `timeline.json` — narration timing that drives every visual beat
- `film/` — the animation: open `film/index.html?play` in a browser (`?play&v` for 9:16)
- `score.py` — synthesized music and sound effects, timed to the film's events

The diagrams are schematic: not to scale, and the Moon's 5.1° orbital tilt is exaggerated.
